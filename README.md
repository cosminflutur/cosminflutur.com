# cosminflutur.com

A dark-walnut personal portfolio and small-business software engineering site.

## Run locally

Open `index.html` directly, or serve the folder with any static web server.

## Customize first

- Replace the three placeholder project cards in `index.html` with real projects.
- Replace the GitHub URL with your GitHub profile.
- Replace `hello@cosminflutur.com` with the email address you want to receive inquiries at.
- Update the About section with your actual degree/program and technologies.

## Deploy

This is a static site and can be deployed to Vercel, Netlify, GitHub Pages, Cloudflare Pages, or similar hosting.
